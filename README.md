# Stopwatch Web App
A simple and responsive Stopwatch built using HTML, CSS, and JavaScript.
It allows users to track time with start, stop, and reset functionality.

# Features
. Start the stopwatch
. Stop/Pause functionality
. Reset timer to zero

# Technologies Used
. HTML
. CSS
. JavaScript (setInterval, DOM Manipulation)

# How It Works
. Click Start to begin the timer
. Click Stop to pause the timer
. Click Reset to set timer back to 00:00:00
